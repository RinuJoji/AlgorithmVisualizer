# Algorithm Visualizer

## Description
A **web-based tool** to visualize sorting algorithms step by step. Supports **Bubble Sort, Selection Sort, and Insertion Sort** with color-coded bars to help understand how sorting works.

---

## Features
- Visualizes **Bubble, Selection, and Insertion Sort**  
- **12-element array** with values displayed on bars  
- Automatically generates a **new array** when selecting a different algorithm  
- **Color codes:**  
  - Red → Unsorted  
  - Yellow → Comparing  
  - Orange → Temporary swap  
  - Green → Sorted  
- Manual control: Generate a new array and sort on demand
